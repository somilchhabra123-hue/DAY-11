*Topic:* Canva Magic Studio — Aviation Mini-Campaign & Brand Consistency

*Goal:* Create *3 consistent aviation designs* using Canva AI and check them for accuracy, branding, professionalism, privacy, and responsible AI use.

*Campaign:* Travel Smart at the Airport
*Audience:* Domestic airline passengers

*Key message:* Check official travel information before arriving at the airport.

### What you have to create

1. *Social-media post* — square
2. *Passenger-awareness poster* — portrait
3. *Presentation visual* — 16:9

### Canva AI tasks

* *Magic Media:* Generate the airport visual.
* *Magic Expand:* Adapt the image to another format and check for distortions.
* *Magic Edit:* Modify one selected element.
* Check for incorrect text, logos, personal data, unrealistic airport details, etc.

### Brand consistency

Keep the same:

* Campaign name
* Dark blue + sky blue + warm yellow
* Sans-serif fonts
* Modern/professional style
* Helpful, calm and trustworthy tone
